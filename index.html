About the project

About Data City Officer

Data City Officer is an interactive educational project designed to introduce cybersecurity and responsible data handling through a game-based learning experience.

The game encourages players to think about the information they share, why data privacy matters, and how everyday choices can help reduce exposure to digital threats.

Through city exploration, character interactions, and decision-making challenges, players encounter practical scenarios involving personal information, account security, and responsible data use.

Frequently asked questions

Frequently Asked Questions

Find out what to expect before you begin.

What is Data City Officer?

It is an educational browser game where players explore a digital city and complete missions about cybersecurity and data privacy.

Who is this game designed for?

It is designed for people interested in learning introductory cybersecurity and data privacy concepts through interactive scenarios. The project does not claim formal accreditation or professional certification.

How do I start playing?

Select Play Game or Start Playing. In the game, explore the city, interact with characters, and complete the available missions. You can move with the keyboard or on-screen touch controls.

Do I need to install anything?

The game runs in a modern web browser as an HTML game. No separate game installation is required when you access a hosted copy.

Can I save my progress?

Game progress is stored in the browser's local storage on the device and browser you use. It is not synced across devices or browsers.
